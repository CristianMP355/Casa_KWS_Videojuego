Construye el proyecto Java completo para IntelliJ IDEA en la carpeta actual utilizando Maven.

Título del Proyecto: "Casa Segura - Smart Home KWS Game Engine"

---

### 1. CONFIGURACIÓN MAVEN (`pom.xml`)
Crea un `pom.xml` compatible con Java 17+ que contenga:
- `com.formdev:flatlaf:3.2.5` (Para la interfaz temática Dark Cyberpunk/Operador de Seguridad).
- `com.google.code.gson:gson:2.10.1` (Para la persistencia de récords e historial).

Crea la estructura de carpetas `src/main/java/com/casasegura/`.

---

### 2. CLASES Y MÓDULOS DE JAVA (`src/main/java/com/casasegura/`)

1. **`Main.java`**:
   - Inicializa el LookAndFeel FlatLaf Dark.
   - Lanza la ventana principal `MainDashboardUI`.

2. **`GameEngine.java` (MOTOR DE DIFICULTAD ELEVADA - ESTILO OPERADOR DE NOCHE)**:
   - **Amenazas Múltiples Simultáneas:** Capacidad de generar de 1 a 3 emergencias al mismo tiempo en distintos sectores (Puerta, Garaje, Ventanas, Televisor, Alarma).
   - **Dificultad Progresiva:**
     - Nivel 1 (0-500 pts): 1 amenaza activa | 4.5s para responder.
     - Nivel 2 (500-1200 pts): 2 amenazas simultáneas | 3.0s para responder.
     - Nivel 3 (1200+ pts): 3 amenazas simultáneas | 1.8s para responder.
   - **Efecto de Anomalía (Tecla `X`):** Si llega el evento de anomalía, congela los monitores por 1.2s e incrementa temporalmente el nivel de riesgo global.
   - Gestión de 3 Vidas, Barra de Riesgo de Seguridad (0-100%), Rachas/Combos y guardado del High Score en `highscore_casa_segura.json`.

3. **`MainDashboardUI.java`**:
   - Ventana principal Swing con navegación en pestañas.
   - **Header:** Switch toggle para **"Modo Simulación por Teclado"** y selector de dificultad manual.
   - **Pestaña 1 - Plano 2D interactivo:** Visualización gráfica de los 5 sectores de la casa (Alarma, Garaje, Puerta, Televisor, Ventanas) con luces de estado dinámicas.
   - **Pestaña 2 - Consola del Operador / Juego:** Tarjetas de emergencia en tiempo real con barras de tiempo regresivo individuales para cada intrusión activa.
   - **Consola Terminal Log:** Registro de eventos con marca de tiempo e iluminación de color según el tipo de alerta.

4. **`KeyController.java`**:
   - Captura global de eventos de teclado mediante `KeyBindings` o `KeyListener` para procesar las entradas emuladas por el puente BLE:
     - `P` $\rightarrow$ Puerta
     - `G` $\rightarrow$ Garaje
     - `V` $\rightarrow$ Ventanas
     - `T` $\rightarrow$ Televisor
     - `A` $\rightarrow$ Alarma
     - `X` $\rightarrow$ Resolver Anomalía

---

### 3. ENTREGA
Genera todo el código limpio, estructurado y listo para compilar e iniciar directamente desde IntelliJ IDEA.
