

Prepara la entrega y el repositorio Git del proyecto en la carpeta actual ejecutando las siguientes tareas:

1. Crea el archivo `.gitignore` con exclusiones para Java/Maven (`target/`, `*.class`), IntelliJ (`.idea/`, `*.iml`), Python (`__pycache__/`, `*.pyc`) y temporales del SO.

2. Crea el archivo `README.md` completo y estructurado con:
   - **Título:** Casa Segura - Smart Home KWS & Game Engine 🛡️🎙️
   - **Arquitectura del Sistema:** Explicando los 3 componentes (Arduino Nano 33 BLE con TinyML, Puente Python `bridge_ble.py`, y Dashboard Java Swing con FlatLaf).
   - **Requisitos Previos:** JDK 17+, Python 3.10+, Arduino IDE 2.x.
   - **Guía de Ejecución:** Paso a paso para subir el sketch de Arduino, correr `python bridge_ble.py` y lanzar `Main.java`.
   - **Tabla de Comandos Vocales:** Mapeo de voz (`"PUERTA"`, `"GARAJE"`, `"VENTANAS"`, `"TELEVISOR"`, `"ALARMA"`) y sus teclas de respaldo sigilosas (`P`, `G`, `V`, `T`, `A`, `X`).

3. Inicializa el repositorio Git (`git init`), agrega todos los archivos (`git add .`), realiza el commit inicial (`git commit -m "feat: Version final Casa Segura KWS - UI 2D unificada y soporte BLE/Teclado"`) y establece la rama principal a `main` (`git branch -M main`).
